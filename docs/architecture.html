Mocksy Architecture

Browser mockup editor — client-side rendering & 100% in-browser video export

Client — editor UI

  • • Next.js 16 · React 19 · TypeScript · Turbopack
  • • next-intl — 57 locales, one source of truth (en.json)
  • • Zustand: editorStore · projectsStore · themeStore
  • • Theme light/dark/system, command palette, shortcuts
  • • Drag&drop upload, undo/redo, share URLs

Export engine — 100% in-browser

  • • canvas.captureStream() → MediaRecorder (WebM VP8)
  • • FFmpeg WASM 32MB — warm-up after first interaction
  • • Shared singleton — no double WASM download
  • • MP4 · WebM · GIF · WebP · PNG · SVG · HTML
  • • No uploads — media never leaves the browser

CI/CD — GitHub Actions (dev)

  • • Lint + Typecheck + audit allowlist + i18n:sync check
  • • Vitest — 1090 unit tests
  • • Lighthouse CI — a11y contrast fixed, green
  • • E2E on macOS runner (canvas.captureStream frames)
  • • VRT — darwin baselines, retries 3 for flaky video
